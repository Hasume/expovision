IT3. Навыки для старта

IT3. Skills to Start • Lesson ID: d2-o

Для входа в IT тебе нужны 3 базовых навыка: уметь искать информацию, уметь задавать вопросы (в том числе AI) и не бояться пробовать.

Навык 1: Поиск информации

Google — это не просто строка поиска. Используй операторы:

  • "точная фраза" — ищет именно эти слова.
  • site:stackoverflow.com python error — ищет только на конкретном сайте.
  • -слово — исключает слово из результатов.

Навык 2: Работа с AI-ассистентами

ChatGPT, Claude, Gemini — это инструменты, как калькулятор. Чем точнее твой запрос, тем лучше ответ.

Плохой запрос: «Как сделать сайт?»

Хороший запрос: «Я новичок. Покажи пошагово, как создать HTML-страницу с заголовком и текстом, используя VS Code.»

Навык 3: Привычка пробовать

Не читай 10 статей — прочитай 1 и сделай. Ошибки — это нормально. Каждая ошибка — это информация о том, как работает система.

Полезные ресурсы

  • freeCodeCamp — бесплатная платформа для практики.
  • MDN Web Docs — лучший справочник по веб-технологиям.

English Version

To enter IT you need 3 basic skills: ability to search for information, ability to ask questions (including to AI), and willingness to try.

Skill 1: Information Search

Google is not just a search bar. Use operators:

  • "exact phrase" — searches for these exact words.
  • site:stackoverflow.com python error — searches only on a specific site.
  • -word — excludes a word from results.

Skill 2: Working with AI Assistants

ChatGPT, Claude, Gemini are tools, like a calculator. The more precise your request, the better the answer.

Bad prompt: "How to make a website?"

Good prompt: "I am a beginner. Show me step by step how to create an HTML page with a heading and text using VS Code."

Skill 3: Habit of Trying

Don't read 10 articles — read 1 and do it. Mistakes are normal. Each error is information about how the system works.

Useful Resources

  • freeCodeCamp — free practice platform.
  • MDN Web Docs — best web technology reference.
