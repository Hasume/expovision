IT2. Компьютер и софт на пальцах

IT2. Computer and Software Basics • Lesson ID: d2-m

Прежде чем писать код или работать с AI, нужно понять, как устроен компьютер и какие программы тебе понадобятся.

Из чего состоит компьютер

  • Процессор (CPU) — «мозг». Выполняет все вычисления. Чем мощнее, тем быстрее работает.
  • Оперативная память (RAM) — «рабочий стол». Хранит данные, с которыми ты работаешь прямо сейчас. 8 ГБ — минимум для разработки, 16 ГБ — комфорт.
  • Накопитель (SSD/HDD) — «шкаф». Хранит все файлы, программы, операционную систему. SSD в 5–10 раз быстрее HDD.
  • Видеокарта (GPU) — нужна для графики, игр и обучения нейросетей. Для обычной разработки встроенной достаточно.

Программы, которые нужны с первого дня

  1. Браузер — Chrome или Firefox с DevTools (встроенные инструменты разработчика, открываются по F12).
  2. Редактор кода — VS Code или Cursor. Бесплатные, мощные, с подсказками.
  3. Терминал — командная строка. На Mac/Linux уже есть. На Windows установи Windows Terminal.
  4. Git — система контроля версий. Позволяет сохранять историю изменений и работать в команде.

Что такое терминал и зачем он нужен

Терминал — это текстовый интерфейс для управления компьютером. Вместо кликов ты пишешь команды.

Базовые команды:

  • ls (или dir в Windows) — показать файлы в папке.
  • cd folder_name — перейти в папку.
  • mkdir new_folder — создать папку.
  • code . — открыть текущую папку в VS Code.

Практическое задание

  1. Установи VS Code или Cursor.
  2. Открой терминал и создай папку для проекта: mkdir my-first-project.
  3. Зайди в неё: cd my-first-project.
  4. Открой в редакторе: code ..

    5. English Version

    Before writing code or working with AI, you need to understand how a computer works and what software you will need.

    What a Computer Is Made Of

    • Processor (CPU) — the "brain." Performs all computations. More powerful = faster.
    • RAM — the "desk." Holds data you are working with right now. 8 GB is minimum for development, 16 GB is comfortable.
    • Storage (SSD/HDD) — the "cabinet." Stores all files, programs, OS. SSD is 5–10x faster than HDD.
    • Graphics Card (GPU) — needed for graphics, games, and neural network training. Integrated GPU is fine for regular development.

    Essential Software From Day One

    1. Browser — Chrome or Firefox with DevTools (press F12).
    2. Code Editor — VS Code or Cursor. Free, powerful, with smart suggestions.
    3. Terminal — command line interface. Already available on Mac/Linux. Install Windows Terminal on Windows.
    4. Git — version control system. Saves change history and enables team collaboration.

    Basic Terminal Commands

    • ls (or dir on Windows) — list files in current folder.
    • cd folder_name — navigate into a folder.
    • mkdir new_folder — create a new folder.
    • code . — open current folder in VS Code.

    Practical Task

    1. Install VS Code or Cursor.
    2. Open terminal and create a project folder: mkdir my-first-project.
    3. Navigate into it: cd my-first-project.
    4. Open in editor: code ..
